# The Bay Area security stack

An interactive field guide: ~282 security companies (mostly SF Bay Area) placed on the machine they protect — nine layers, three planes (See / Test / Govern).

- `index.html` — the 3D model (three.js, self-contained, no build step). Open it in a browser.
- Search a company to fly to it. Search a company that isn't on the map and it explains why + shows the closest ones + a web lookup.

Research by Divya. Draft, September 2026 — stages and funding are approximate.
